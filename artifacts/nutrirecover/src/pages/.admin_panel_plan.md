# Admin Panel Plan

## Backend Changes

### 1. `old-project/artifacts/api-server/src/routes/admin.ts` (NEW)
- Admin middleware: simple secret key check (`x-admin-key` header)
- `POST /admin/foods` - Add new food
- `PUT /admin/foods/:id` - Update nutrient values
- `DELETE /admin/foods/:id` - Delete food
- `POST /admin/dataset/upload` - Upload new Excel dataset (replaces all foods)
- `GET /admin/dataset/export` - Export current dataset as JSON/CSV
- `GET /admin/foods/search?q=` - Search foods by name

### 2. `old-project/artifacts/api-server/src/routes/index.ts` (MODIFIED)
- Import and register adminRouter

### 3. `old-project/lib/api-zod/src/generated/types/food.ts` (USED)
- The existing `Food` interface already covers all fields needed

## Frontend Changes

### 1. `old-project/artifacts/nutrirecover/src/pages/AdminPanel.tsx` (NEW)
- Access code gate: prompt user for admin key
- Features:
  - Search foods with real-time filtering
  - Table view of all foods with nutrient columns
  - Add food form (modal/section)
  - Edit food form (inline or modal)
  - Delete food with confirmation
  - Upload dataset (Excel file upload via multipart)
  - Export dataset (download as JSON)
- Uses `fetch()` directly (not generated hooks) since admin endpoints are custom

### 2. `old-project/artifacts/nutrirecover/src/App.tsx` (MODIFIED)
